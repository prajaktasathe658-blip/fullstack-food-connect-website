# Food Connect

Food Connect is a full-stack food donation and reduction platform that connects food donors with NGOs to reduce food wastage.

## Features

- User registration and login
- Donor and NGO roles
- JWT authentication
- Donors can post available food
- NGOs can request food
- Food request management
- Food availability/status tracking
- Protected routes
- Admin dashboard
- MongoDB database

## Technologies Used

### Frontend
- React.js
- Vite
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
